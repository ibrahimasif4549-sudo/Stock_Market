# Stock Market Shock & Recovery Analyzer

## About the Project
This is a Python script I developed to assist with my stock market analysis. It fetches historical stock data and analyzes the recovery path of a stock after a significant "shock" day (a drop of 5% or more), excluding dividend-related drops. It outputs a summary and visualizes the 20-day recovery chart.

## Built With
* Python
* Pandas (for data manipulation)
* Matplotlib (for chart generation)
* yfinance (for fetching stock data)
